# 삼각비의 활용 — 삼각측량과 GPS (수업용 웹 학습지)

중학교 3학년 <삼각비의 활용> 단원용 자료입니다.
GitHub Pages 에 index.html 하나만 올리면 바로 사용할 수 있습니다.

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 학생용 웹 학습지 (그림 · 대본 · 빈칸 · VPython 코드 복사) |
| `Code.gs` | 학생 응답을 구글 스프레드시트에 저장하는 Apps Script |
| `spherical_coords_webvpython.py` | 자료 A · 구면좌표계 시뮬레이션 |
| `gps_trilateration_webvpython.py` | 자료 B · GPS 삼변측량 시뮬레이션 |
| `images/fig1.png ~ fig4.png` | 수업용 그림 (직접 내려받아 넣어 주세요) |

## 1. GitHub Pages 배포

1. 새 저장소를 만듭니다. (예: `trig-gps-lesson`)
2. `index.html` 을 저장소 최상위에 올립니다.
3. Settings > Pages > Source 를 `Deploy from a branch`, Branch 를 `main / (root)` 로 지정하고 Save.
4. 1~2분 뒤 `https://<사용자이름>.github.io/<저장소이름>/` 로 접속됩니다.

### 그림을 저장소에 함께 올리기 (권장)

현재 그림 4장은 외부 주소에서 불러옵니다. 학교 네트워크에서 외부 이미지가 막히는 경우가 있으므로,
그림을 내려받아 `images/` 폴더에 넣고 `index.html` 안의 `<img src="...">` 주소를
`images/fig1.png` 처럼 바꾸어 두시면 안전합니다.

## 2. 저장 / 불러오기 설정 (Google Apps Script)

1. 구글 스프레드시트를 하나 만들고, 주소창에서 `/d/` 와 `/edit` 사이의 문자열(스프레드시트 ID)을 복사합니다.
2. 그 시트에서 확장 프로그램 > Apps Script 를 열고 `Code.gs` 내용을 붙여 넣습니다.
3. 맨 위 `SHEET_ID` 에 1번에서 복사한 값을 넣습니다.
4. 배포 > 새 배포 > 유형 [웹 앱]
   - 실행 계정 : 나
   - 액세스 권한 : **모든 사용자**
5. 배포 후 나오는 `.../exec` 주소를 복사해서, `index.html` 의 아래 줄에 붙여 넣습니다.

```js
var GAS_URL = "https://script.google.com/macros/s/AKfycb....../exec";
```

### 동작 방식

- 학생이 **학번 · 이름**을 넣고 답을 채운 뒤 **저장** 을 누르면 스프레드시트에 한 줄로 기록됩니다.
- 같은 학번 · 이름으로 다시 저장하면 그 줄이 갱신됩니다. (중복 행이 생기지 않습니다.)
- 다음 시간에 같은 학번 · 이름을 넣고 **불러오기** 를 누르면 이전 답이 그대로 채워집니다.
- 인터넷이 끊겨도 브라우저에 자동 임시 저장되므로 새로고침해도 답이 남아 있습니다.
- 채점할 때는 Apps Script 편집기에서 `응답정리` 함수를 한 번 실행하면
  문항별 열로 펼쳐진 `정리` 시트가 만들어집니다.

## 3. Web VPython 실행

- 로그인 없이 실행 : https://trinket.io/glowscript
- 공식 사이트 : https://www.glowscript.org/

학습지 안의 **코드 복사** 버튼을 누른 뒤, 위 사이트의 편집창에 붙여 넣고 Run 하면 됩니다.

### 자료 A · 구면좌표계
- 북극이 화면 위쪽(+z 축)에 오도록 맞추어 두었습니다.
- 지구 그림과 도시 표시가 어긋나 보이면 **지구 그림 경도 맞추기** 슬라이더로 맞춘 뒤,
  그 값을 코드 위쪽 `TEX_LON_OFFSET` 에 적어 두면 다음부터 바로 맞은 상태로 열립니다.
- 지구 그림 없이 격자만 보고 싶으면 `USE_TEXTURE = False` 로 바꾸세요.

### 자료 B · GPS 삼변측량
- 버튼으로 위성을 1개 → 2개 → 3개 → 4개로 늘려 가며 보여 주세요.
- 위성 3개일 때 나타나는 흰 점 2개 중 하나가 지구 밖에 있다는 것이 핵심 장면입니다.
